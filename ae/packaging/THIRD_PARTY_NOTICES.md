# Third-party notices

## Adobe CEP bridge

The panel includes a local copy of the Adobe CEP bridge at `com.velo.curveeditor/js/CSInterface.js`. The original copyright and license notices are preserved in that file. Refer to those notices for the bridge's terms.

The bridge is bundled locally so Velo does not depend on another extension or a remote script at runtime.

Velo's panel code, curve model, interface text and styles are included as readable source files. No third-party web framework, remote font, online service, Node.js runtime or Python runtime is bundled or required by the panel.

The `docs/assets/velo-banner.svg` file in the source repository is an original brand illustration, not a screenshot of an After Effects project or a recording of user data.
