# Velo for After Effects

Velo 的 AE CEP 面板，版本 `1.2.0`。包含 Bezier、Elastic、Bounce、22 个曲线预设、双控制柄、连续滑杆、值／速度编辑、JSON、反向、预设管理、EaseCopy，以及中文／English／日本語／한국어界面。

## 界面语言与主题

在“设置 → 界面 → 语言”中选择中文、English、日本語或 한국어。语言设置保存在现有面板设置中，界面、内置预设、动态状态及 EaseCopy 文案同步切换；用户预设名称、曲线 JSON 和宿主数据保持原始内容，不进行机器改写。

设置页与主界面共用根节点主题变量，页签、开关、主按钮、焦点和相关 hover 随主题色更新；中性表面和文字层级保持不变。窄窗口保留操作入口，设置页签不拆字换行；英文视图使用 `Val / Spd`，英／日／韩检查按钮使用 `Inspect / 検査 / 검사`，导入导出采用短标签，完整的辅助说明仍保留。英／日／韩设置首页显示 `UI`，其余页签保留对应语言。

曲线颜色、画布背景和控制点颜色均使用面板内取色弹窗，不依赖 CEP 不支持的系统颜色窗口。弹窗支持饱和度／亮度画布、色相、Hex、RGB 与快捷色板，并提供即时预览、无效输入保护、应用持久化、取消恢复、Esc 关闭和 Tab 焦点循环。

原生 AE 标签只显示 `Velo`，不包含额外绿点。顶部在 Bezier 左侧保留“就绪／提醒／处理中／错误”短状态，宽度按内容计算，与模式按钮保持紧凑间距，不再被完整消息撑开。完整提醒和错误统一使用右侧滑入通知栏，参考 Cavalry 的状态图标、短消息与统一通知行为；通知约 4.5 秒后自动退出，悬停或键盘聚焦时暂停，支持手动关闭、Escape、消息替换及减少动效。状态变化不再改写白色 macOS 标题栏。

## Bounce 速度背景

Bounce 碰撞时的速度反向及导数间断是正常物理行为。速度背景在真实碰撞点分别绘制线段，不再把间断两侧连接成不存在的斜线；值曲线仍连续，公开采样数据与 AE 写入语义不变。采样循环只归一化一次，显示断点随现有缓存计算，避免重复归一化和临时点数组分配。

## macOS 安装

1. 退出 After Effects。
2. 将压缩包中的 `com.velo.curveeditor` 文件夹复制到：
   `~/Library/Application Support/Adobe/CEP/extensions/`
3. 如果系统尚未允许 CEP 调试扩展，在终端执行（将 `7` 替换为你的 CSXS 主版本）：
   `defaults write com.adobe.CSXS.7 PlayerDebugMode 1`
4. 重新打开 AE，在 `窗口 → 扩展 → Velo` 打开面板。升级后如果仍显示旧页面，使用 AE 菜单重新打开面板，使 CEP 进程重新加载。

不需要联网，也不依赖其他扩展。`CSInterface.js` 是 Adobe 的本地 CEP 桥库，原有许可声明保留在文件中。

## 曲线与预设

1. 激活一个合成，在数值属性上选择至少两个时间上相邻的关键帧。
2. 调整曲线或选择预设；Bezier 可用“值／速”切换值曲线和速度编辑。
3. 点击“检查目标”确认属性与段数，再点击 `Apply`。
4. 执行一次 AE 撤销即可恢复本次多属性应用前的状态。

- 单段标量 Bezier 写入 AE 原生 Temporal Ease，不增加中间关键帧；数组、Elastic／Bounce 和多段 Bezier 使用采样关键帧，单段最多 512 个采样间隔。
- 在 Bezier 值视图或速度视图双击画布可插入锚点，插入使用 de Casteljau 分割并保持原曲线形状。两种视图使用同一曲线模型；锚点及两侧手柄可拖动。值视图右键打开“平滑点位／保形删除／删除点位”菜单，Shift+右键直接保形删除。保形删除将关键帧转为不参与显示和 Apply 显式锚点采样的内部形状节点，保留原分段几何，因此值曲线与速度不变；普通删除仍会重连并可能改变形状。
- 内部锚点的左右手柄在距连续切线 8 个屏幕像素以内时吸附并高亮，菜单“平滑点位”使用同一切线模型。主操作区“平滑”自动分析全部锚点，简化曲率连续的冗余可见点，保留极值、停顿和必要的负速度，不机械强制所有中间速度大于零。超过 4 个可见锚点后编辑内容逐步增高，超出外窗时可滚动；当前 CEP 不保证扩大外窗。
- 支持多段反向、v2 JSON 和预设往返；内部形状节点随 JSON 保存并在反向时镜像。多段速度视图显示并编辑真实端点导数手柄；速度视图双击与值视图共用同一保形插点算法。Elastic／Bounce 双击仍显示专用多点位提示。
- 支持一次应用多个数值属性，但所有选中关键帧必须连续。多段 Apply 使用包含锚点位置的排序去重时间采样，并兼容 AE 帧时间量化。
- 预设只显示当前模式的内容，左右侧栏使用双列卡片。预设卡支持右键隐藏内置、删除用户预设和拖拽排序；CEP 使用指针拖动，浏览器预览保留 HTML5 拖放，两者共用同一排序函数。设置按“界面／预设／主题／图形”分类，支持四向预设位置、40–104 卡片尺寸、恢复隐藏、减少动效、主题颜色、网格、曲线精度、速度强度和设置持久化。
- “导出曲线预设”通过 AE 打开系统保存对话框，可选择保存位置和文件名；取消时不写文件，成功后显示真实保存路径。`velo-presets` v2 JSON 包含全部 22 个内置预设、用户预设、内置项隐藏状态及完整排序，未隐藏的项也不会遗漏。v2 导入恢复隐藏与排序；用户预设遇到已有 ID 时重映射，不覆盖已有内容。继续兼容 v1 和 TD 的 `name` / `curve` 数据，旧文件只追加用户预设，不替换隐藏与排序。非法 JSON、缺少内置项、无效曲线或超出 32 个用户预设上限时，不写入现有配置。
- Shape、蒙版路径、非数值属性、空选区及跳帧选区不会被写入，面板会给出错误原因。
- 应用前请确认时间轴或合成查看器是目标合成的活动上下文，不要只让项目面板中的合成名称高亮。

## 播放预览

光点默认以 2 秒为周期沿值曲线移动，在速度视图中沿同一函数的真实导数移动；切换模式或拖动手柄时使用同一曲线状态。画布不显示悬浮时长或速度标注。后台窗口暂停，返回后不跳帧；减少动效可暂停自动播放，关闭后若此前正在播放则恢复。预览只是曲线演示，不驱动 AE 时间轴。

速度视图的端点与水平拉杆使用同一速度域和真实端点导数，值视图保持原控制柄映射。速度编辑期间固定纵轴，拖动任一侧手柄时另一侧保持原屏幕位置，松手后也保持该视口；更换曲线或点击“图形 → 适配当前曲线”时才重新计算范围，并在实际曲线上下留白，便于向正负两个方向调整。圆形控制柄距零线 8 个屏幕像素以内时，对应端点速度精确吸附为零，零线以当前主题色高亮；离开后仍可自由调整负速度。未变化的曲线复用采样；预览只更新光点，拖拽、面板尺寸和窗口尺寸变化按帧合并主画布绘制，并去重兼容鼠标事件。以上调整不改变曲线输出或 EaseCopy 行为。

## EaseCopy

1. 在 AE 中选择一个或多个数值关键帧，点击 EaseCopy 的“复制”。
2. 选择目标关键帧，使用“粘贴缓动”或“粘贴数值”。目标数量必须与源相同，或是源数量的整数倍。
3. “直通”保留左右速度连续的内部关键帧数值及相邻缓动；“清空”只清空面板缓冲区，不修改 AE 数据。

- 粘贴缓动保留目标数值；粘贴数值保留目标缓动。
- 支持标量和等长数值数组；单属性缓动可复制到多维属性，数值维度不匹配会在写入前拒绝。
- 每次粘贴使用一个 UndoGroup，可执行一次 AE 撤销恢复。

## 验证范围

v1.2.0 统一当前多锚点编辑、完整预设配置、原生文件流程、紧凑状态与右侧通知。原生标签继续只显示 `Velo`，不改写 macOS 标题栏；EaseCopy 数值写入后统一恢复目标缓动，剪贴板权限被拒绝时进入既有复制／手动粘贴回退。

性能方面，`segmentsKeyCache` 按分段数组引用复用状态键的序列化结果，标量仍每次读取，分段替换立即重算。12 段曲线独立测量中，28,000 次重复读取在预热后不再序列化数组；同一键值和校验和不变，标量与分段失效断言通过。该路径中位耗时由约 `2.46µs` 降至 `0.92µs`，不代表 AE 整体提速。真实 CEP 预览复测使用同一 12 段曲线和精度，缓存前 90 个观察帧中分段序列化 90 次，缓存后为 0 次，预览清屏分别为 62 和 65 帧，曲线输出完全一致；不以观察帧率宣称整体性能提升。采样、缩略图、预览和设置写入继续沿用既有缓存与合并策略。
