# Velo 1.2.0 for After Effects — Release announcement / 发布文案

## English

**Velo 1.2.0 brings direct curve, speed and keyframe control to After Effects.** Edit Bezier, Elastic and Bounce, preserve shape while inserting or deleting points, transfer complete preset configurations and use EaseCopy without leaving the local CEP panel.

The native tab stays simply `Velo`: compact status stays beside the mode controls, and full feedback appears in a separate notification. The package includes bilingual offline guides and SHA-256 verification. Windows receives static/package checks, not a claim of Windows AE host verification.

Download: https://github.com/luoboruodai/velo-curve-editor/releases/tag/v1.2.0

TouchDesigner v1.1.0 remains available separately. A one-click AE/Cavalry/TouchDesigner installer is not part of this release.

## 中文

**Velo 1.2.0 为 After Effects 提供直接的曲线、速度与关键帧控制。** 支持 Bezier、Elastic、Bounce、保形插点／删除、完整预设配置传输与 EaseCopy，全部在本地 CEP 面板中完成。

原生标签只显示 `Velo`，短状态留在模式按钮旁，完整提醒使用独立通知。安装包包含双语离线指南与 SHA-256 校验；Windows 仅做静态／打包检查，不宣称 Windows AE 宿主实测。

下载：https://github.com/luoboruodai/velo-curve-editor/releases/tag/v1.2.0

TouchDesigner v1.1.0 继续独立提供，本次不包含 AE／Cavalry／TouchDesigner 一键安装器。

# Velo 1.1.0 — Release announcement / 发布文案

## English

**Velo 1.1.0 is available: native curve editing and animation-keyframe authoring for TouchDesigner.**

Edit Bezier, Elastic and Bounce curves with synchronized speed visualization, flexible handles, presets and EaseCopy. When you need native animation data, use **Settings → Graph → 写入关键帧** to create an Animation COMP with 258 editable linear keys—without changing the live 257-sample `fade` output.

Velo uses native TouchDesigner nodes only: no WebRender, HTML browser or external frontend runtime.

Download: https://github.com/luoboruodai/velo-curve-editor/releases/tag/v1.1.0

Verified on macOS with TouchDesigner 2025.31550. The same native TOX is provided for Windows; Windows runtime verification is not claimed.

## 中文

**Velo 1.1.0 已发布：为 TouchDesigner 提供原生曲线编辑与动画关键帧写入。**

支持 Bezier、Elastic、Bounce、同步速度显示、自由拉杆、预设与 EaseCopy。需要原生动画数据时，可通过 **设置 → 图形 → 写入关键帧** 创建包含 258 个可编辑线性关键帧的 Animation COMP，同时保持原有 257 样本 `fade` 实时输出不变。

Velo 全部使用 TouchDesigner 原生节点，不依赖 WebRender、HTML 浏览器或外部前端运行时。

下载：https://github.com/luoboruodai/velo-curve-editor/releases/tag/v1.1.0

已在 macOS / TouchDesigner 2025.31550 验证；Windows 提供同一原生 TOX，但不宣称已完成运行实测。
