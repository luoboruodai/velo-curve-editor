# Velo 1.1.0 — Release announcement / 发布文案

## English

**Velo 1.1.0 is available: native curve editing and animation-keyframe authoring for TouchDesigner.**

Edit Bezier, Elastic and Bounce curves with synchronized speed visualization, flexible handles, presets and EaseCopy. When you need native animation data, use **Settings → Graph → 写入关键帧** to create an Animation COMP with 258 editable linear keys—without changing the live 257-sample `fade` output.

Velo uses native TouchDesigner nodes only: no WebRender, HTML browser or external frontend runtime.

Download: https://github.com/luoboruodai/velo-curve-editor/releases/tag/v1.1.0

Verified on macOS with TouchDesigner 2025.31550. The same native TOX is provided for Windows; Windows runtime verification is not claimed.

## 中文

**Velo 1.1.0 已发布：为 TouchDesigner 提供原生曲线编辑与动画关键帧写入。**

支持 Bezier、Elastic、Bounce、同步速度显示、自由拉杆、预设与 EaseCopy。需要原生动画数据时，可通过 **设置 → 图形 → 写入关键帧** 创建包含 258 个可编辑线性关键帧的 Animation COMP，同时保持原有 257 样本 `fade` 实时输出不变。

Velo 全部使用 TouchDesigner 原生节点，不依赖 WebRender、HTML 浏览器或外部前端运行时。

下载：https://github.com/luoboruodai/velo-curve-editor/releases/tag/v1.1.0

已在 macOS / TouchDesigner 2025.31550 验证；Windows 提供同一原生 TOX，但不宣称已完成运行实测。
